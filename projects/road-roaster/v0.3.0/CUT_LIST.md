## 2. Sheet Metal Cut Templates (14-Gauge Steel)

The 4 side panels are cut from 14-gauge mild steel sheet. Each panel integrates a $2.0''$ vertical skirt at the bottom and a trapezoidal pyramid facet at the top.

```
       [ 4.0" Apex Top ]
           +-------+
          /         \
         /  Pyramid  \   Slant Height: 9.60" (244 mm)
        /    Facet    \  Side Angle: 38.0° from vertical
       /               \
      +-----------------+  <-- Base Line (18.0" wide)
      |  2.0" Skirt     |  Vertical Extension
      +-----------------+
        [ 18.0" Base ]
```

### Exact Panel Dimensions & Cut Specs:

- **Panel Quantity**: **4 matching pieces** (Front, Left, Right, Rear).
- **Overall Panel Height**: $11.60''$ ($294.6\text{ mm}$) = $2.0''$ skirt + $9.60''$ slant height.
- **Bottom Width (Skirt)**: $18.0''$ ($457.2\text{ mm}$).
- **Top Width (Apex)**: $4.0''$ ($101.6\text{ mm}$).
- **Side Cut Angle**: Cut side edges at a $38.0^\circ$ taper inward from the base line to the top apex ($52.0^\circ$ angle relative to horizontal base).
